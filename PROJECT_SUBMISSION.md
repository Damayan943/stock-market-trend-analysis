# Project Submission Notes

## Project title
Five-Year Stock Market Trend Analysis Using SQL & Power BI

## Objective
Analyze approximately five years of daily prices for the NIFTY 50 index and selected NSE-listed companies to compare performance, trends, trading activity, and historical volatility.

## Tools
- Python and pandas: retrieve and prepare historical market data
- SQL Server: store records and calculate returns, moving averages, monthly performance, and volatility
- Power BI Desktop: create interactive dashboard pages and slicers

## Expected deliverables
1. `data/stock_prices.csv` and `data/stock_prices_enriched.csv` generated by the downloader
2. SQL Server database `StockMarketAnalysis` with stock-price data and analytical views
3. Power BI report with Market Overview, Stock Comparison, Returns & Risk, and Volume & Activity pages

## Suggested resume bullet (use only after completing and validating the work)
Developed a five-year Indian stock-market analysis workflow using Python, SQL Server, and Power BI; prepared historical price data, calculated daily returns and moving averages with SQL, and designed interactive visuals to compare market trends, performance, trading volume, and historical volatility.

## Important
This repository is a starter codebase and dashboard build guide. It does not contain a finished `.pbix` report or bundled market data. Run the scripts, validate the downloaded records, and build/save the report in Power BI Desktop before claiming the project as completed. Historical analysis is educational and is not investment advice.
